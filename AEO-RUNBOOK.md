# Aaron Family Livestock AEO Operations Runbook

This checklist covers the off-site steps that require access to search-engine and business accounts. Complete it after each major site deployment and review it monthly.

## Deployment Day

1. Confirm these live URLs return HTTP 200:
   - `/`
   - `/angus-genetics/`
   - `/sires/`
   - `/embryo-calves/`
   - `/show-cattle/`
   - `/show-record/`
   - `/about/`
   - `/contact/`
   - `/robots.txt`
   - `/sitemap.xml`
2. Confirm the canonical on every page matches its live URL.
3. Run every page through Google's Rich Results Test and Schema.org Validator.
4. Inspect mobile and desktop layouts and test every navigation, phone and email link.

## Google Search Console

1. Submit `https://aaronfamilylivestock.com/sitemap.xml`.
2. Request indexing for the home page and each new topic page.
3. Record indexed-page count, impressions, clicks and top queries.
4. Review Page Indexing and Core Web Vitals reports weekly for the first month.

## Bing Webmaster Tools

1. Import or verify the site.
2. Submit the XML sitemap.
3. Submit the eight primary URLs through URL Submission.
4. Enable IndexNow only with a verified key and deployment integration.

## Content Update Rhythm

- Update the embryo-calves page when calves are born.
- Add only verified registration numbers, dates, photos and availability.
- Add a dated calf-crop update after evaluation.
- Add new show results with event, date, class and animal details.
- Refresh sitemap `lastmod` only for pages that materially changed.

## Success Measures

Review at 30, 60 and 90 days:

- Indexed pages
- Non-branded impressions
- Branded searches
- Qualified calls and emails
- Referring domains and partner mentions
- AI answers that cite AFL
- Accuracy of AI-generated business facts
